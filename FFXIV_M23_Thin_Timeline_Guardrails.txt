FFXIV M23 — THIN TIMELINE & LOCATION GUARDRAILS

Purpose
-------
This document is NOT an encyclopedia of Final Fantasy XIV lore.
MiMo already demonstrates strong broad FFXIV knowledge. The purpose of this layer is to keep roleplay grounded to the correct era, zone, cast availability, and spoiler state.

Core model
----------
Track:

EXPANSION
→ PATCH / PATCH RANGE
→ ARC / ZONE PHASE
→ CURRENT LOCATION

Each active arc stores only:
- already happened
- currently relevant
- not yet happened / spoiler locked
- important cast availability
- next transition condition
- optional side-content completion state

Context priority
----------------
1. Current location / zone
2. Current arc
3. Patch state
4. Expansion state
5. Completed optional stories
6. Older canon only when directly relevant

The AI may propose progression, but only the deterministic engine may actually advance the timeline state.

IMPLEMENTATION RULES
==================================================

The timeline system should be editable and data-driven.
Do not bury FFXIV story state in model prompts or renderer conditionals.

A Run should store a compact TimelineState object similar to:

{
  expansion,
  patch,
  arcId,
  locationId,
  completedMilestones[],
  lockedKnowledgeIds[],
  optionalContentStates{}
}

The prompt context generated from this object should be concise.

The AI should be told:
- where it is
- what has happened
- what is happening now
- what is not yet known

Do NOT send the entire FFXIV timeline every turn.
